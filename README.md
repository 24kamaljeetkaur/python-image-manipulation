# Python Image Manipulation Project

A simple Python project for image processing using NumPy and Pillow.

## Features
- Display image information and pixel values
- Flip images horizontally and vertically
- Crop images using coordinates
- Adjust image brightness
- Save processed images

## Technologies Used
- Python
- NumPy
- Pillow (PIL)

## Installation

```bash
pip install numpy pillow
```

## Usage

Place your input image in the project folder and run:

```bash
python image_processor.py
```

The processed image will be saved as `output.png`.

## Learning Objectives

This project demonstrates Python classes, object-oriented programming, NumPy array slicing, pixel manipulation, and image processing.
